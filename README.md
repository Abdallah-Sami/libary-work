## 2. التقنيات المستخدمة

### اللغات والتقنيات الأساسية

| التقنية | الإصدار / النوع | الاستخدام |
|---------|----------------|----------|
| **PHP** | PHP 7+ | لغة البرمجة الخلفية الرئيسية |
| **MySQL** | MySQLi | قاعدة البيانات |
| **HTML5** | — | هيكل الصفحات |
| **CSS3** | — | التصميم والتنسيق |
| **JavaScript (Vanilla)** | ES6+ | التفاعلية في المتصفح |

### المكتبات الخارجية

| المكتبة | الاستخدام | طريقة التضمين |
|---------|----------|--------------|
| **JsBarcode** | توليد الباركود (CODE128) لملصقات الكتب | CDN |
| **PhpOffice/PhpSpreadsheet** | تصدير ملفات Excel | Composer (مثبتة) |
| **TechnicCom/TCPDF** | توليد ملفات PDF | Composer (مثبتة) |

### تقنيات التصدير

| التصدير | الصيغة | الطريقة |
|---------|-------|---------|
| **Excel** | XML SpreadsheetML (.xls) | PHP يولّد XML مباشرةً بدون مكتبات |
| **Word** | HTML → .doc | JavaScript `Blob` + تنزيل تلقائي |
| **PDF** | HTML → طباعة | صفحة HTML مُهيّأة للطباعة بـ CSS |
| **طباعة مباشرة** | HTML → Print | `window.print()` |

### نظام الجلسة والمصادقة

- **بدون Sessions** — يستخدم **Cookies + HMAC-SHA256** بدلاً من `$_SESSION`
- التوكن مُشفّر ويحتوي على: اسم المستخدم + وقت الإنشاء + توقيع HMAC
- مدة الجلسة: **7 أيام**

## 5. نظام تسجيل الدخول والمصادقة

### الملفات: `login.php` + `auth.php` + `logout.php`

#### بيانات الدخول
```
اسم المستخدم: Eid2025
كلمة المرور:  Asd741852
```

#### كيف يعمل النظام؟

```
1. المستخدم يُدخل البيانات في login.php
2. auth.php::login() تتحقق من اسم المستخدم وكلمة المرور
3. عند النجاح → يُنشئ توكن بصيغة: "username|timestamp"
4. يُشفّر التوكن بـ HMAC-SHA256
5. يُخزَّن في Cookie آمن (HttpOnly) لمدة 7 أيام
6. كل صفحة محمية تستدعي requireAuth()
7. requireAuth() تتحقق من صلاحية التوكن
8. إذا انتهت المدة أو التوكن غير صالح → redirect إلى login.php
```

#### الدوال الرئيسية في `auth.php`

| الدالة | الوصف |
|--------|-------|
| `createToken($user)` | ينشئ توكن HMAC-SHA256 موقّع |
| `verifyToken($token)` | يتحقق من صلاحية التوكن والمدة |
| `login($user, $pass)` | يتحقق من البيانات ويضبط الـ Cookie |
| `logout()` | يحذف الـ Cookie |
| `isLoggedIn()` | يُرجع true إذا المستخدم مسجّل دخول |
| `getUser()` | يُرجع اسم المستخدم من التوكن |
| `requireAuth()` | يُعيد توجيه إلى login.php إذا غير مسجّل |

#### مميزات صفحة تسجيل الدخول
- تصميم احترافي بخلفية متدرجة
- أيقونات SVG للحقول
- زر إظهار/إخفاء كلمة المرور
- رسالة خطأ عند بيانات خاطئة
- دعم كامل للغة العربية RTL

## 6. إدارة الكتب

### الملفات: `add_book.php` + `save_book.php` + `view_books.php` + `edit_book.php` + `delete_book.php` + `delete_all_books.php`

#### العمليات المتاحة

| العملية | الملف | الوصف |
|---------|-------|-------|
| إضافة كتاب | `add_book.php` → `save_book.php` | إدخال بيانات كتاب جديد |
| عرض الكتب | `view_books.php` | عرض قائمة بجميع الكتب مع إحصائيات |
| تعديل كتاب | `edit_book.php` | تعديل بيانات كتاب موجود |
| حذف كتاب | `delete_book.php` | حذف كتاب واحد بالمعرّف |
| حذف الكل | `delete_all_books.php` | حذف جميع الكتب دفعة واحدة |

#### حقول الكتاب
- **Call No** — رقم التصنيف الخاص بالكتاب
- **Cutter No** — رقم الكاتر (مُعرّف المؤلف)
- **Accession No** — رقم الاستيعاب (رقم تسلسلي فريد)
- **Campus** — الحرم الجامعي الذي يوجد فيه الكتاب

---

### طباعة ملصقات الكتب — `print_label.php`

#### الميزات
- يسحب بيانات الكتب من قاعدة البيانات (أول 40 كتاب)
- يعرض **10 ملصقات في الصفحة الواحدة** (عمودان × 5 صفوف)
- كل ملصق يحتوي على:
  - شعار الكلية
  - **رقم التصنيف** (Call No)
  - **رقم الكاتر** (Cutter No)
  - **رقم الاستيعاب** (Accession No)
  - **باركود** بصيغة CODE128 (يستخدم مكتبة JsBarcode)
- مُهيّأ للطباعة على A4 عمودي

#### مكتبة JsBarcode
```html
<!-- تُحمَّل من CDN -->
<script src="https://cdn.jsdelivr.net/npm/jsbarcode@3.11.6/dist/JsBarcode.all.min.js"></script>
```
تُولّد الباركود داخل عنصر `<svg>` بصيغة CODE128.

---

### طباعة كعوب الكتب (Spines) — `print_spine.php`

#### الميزات
- يسحب بيانات الكتب (أول 40 كتاب)
- **4 Spines في كل صف**
- النص مُدار 90 درجة لمحاكاة شكل كعب الكتاب الحقيقي
- كل Spine يحتوي على: YICM + رقم التصنيف + رقم الكاتر
- حدود مرئية لسهولة القص بعد الطباعة
- مُهيّأ للطباعة أفقي (Landscape)

## 9. نموذج صرف المكافأة

### الملفات: `coop_reward_form.php` → `coop_reward_print.php`

### المرحلة الأولى — نموذج الاختيار (`coop_reward_form.php`)

#### ما تفعله هذه الصفحة:
1. تعرض حقول **الفترة الأولى** (مطلوبة): من — إلى (يوم/شهر)
2. تعرض حقول **الفترة الثانية** (اختيارية): من — إلى (يوم/شهر)
3. تعرض قائمة بجميع طلاب التدريب التعاوني مع:
   - Checkbox لاختيار الطالب
   - بيانات الطالب (الاسم، الرقم، التخصص، البنك)
   - حقل إدخال **عدد أيام الغياب** (القيمة الافتراضية: "لا يوجد")
4. زر "تحديد الكل"
5. عند الضغط على "عرض نموذج الصرف":
   - تتحقق من اختيار طالب واحد على الأقل
   - تحزم البيانات في JSON
   - تخزّنها في **sessionStorage**
   - تفتح `coop_reward_print.php` في تبويب جديد

#### البيانات المُخزَّنة في sessionStorage:
```javascript
reward_students    // مصفوفة JSON: [{id, name, iban, bank, absence}]
reward_period_from // الفترة الأولى — من
reward_period_to   // الفترة الأولى — إلى
reward_period_from2 // الفترة الثانية — من (قد تكون فارغة)
reward_period_to2   // الفترة الثانية — إلى (قد تكون فارغة)
```

---

### المرحلة الثانية — صفحة الطباعة (`coop_reward_print.php`)

#### ما تعرضه الصفحة:

**هيدر الوثيقة:**
- شعار الهيئة الملكية (يمين فقط)
- اسم المؤسسة: الهيئة الملكية للجبيل وينبع — الهيئة الملكية بينبع
- إدارة تطوير الموارد البشرية

**عنوان النموذج:**
- برنامج التدريب التعاوني
- نموذج صرف المكافأة الشهرية
- لطلاب التدريب التعاوني

**الجدول الرئيسي (RTL — يبدأ من اليمين):**

| م | اسم المتدرب | الغياب | الفترة الأولى (من/إلى) | الفترة الثانية (من/إلى) | البنك | الآيبان (24 خانة) |
|---|------------|--------|----------------------|------------------------|-------|------------------|

> **ملاحظة:** إذا لم تُدخل فترة ثانية، تظهر خانتا الفترة الأولى فقط.
> كل حرف من رقم الآيبان (24 حرف) يُعرض في خانة منفصلة.

**قسم التوقيعات (أسفل الجدول):**

```
مشرف التدريب               مدير الإدارة
نواف العتيبي            د/ سوزان الدوبي
__________________       __________________
      التوقيع                 التوقيع
```

**أزرار التحكم (تختفي عند الطباعة):**
- 🖨️ طباعة — `window.print()`
- 📄 تصدير Word — يُنزّل ملف `.doc`
- ✖ إغلاق — `window.close()`

#### كيف يعمل تصدير Word؟
```javascript
function exportToWord() {
    // 1. يأخذ محتوى الصفحة (HTML + CSS)
    // 2. يحزمه في Blob بنوع application/msword
    // 3. يُنشئ رابط تنزيل مؤقت
    // 4. ينزّل الملف باسم: كشف_مكافأة_التدريب_التعاوني.doc
    // 5. يحذف الرابط المؤقت
}
```
الملف `.doc` يُفتح في Microsoft Word ويمكن إضافة التوقيعات يدوياً.
